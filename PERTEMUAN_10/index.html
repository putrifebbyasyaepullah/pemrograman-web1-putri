Pengertian Semantic HTML

Semantic HTML adalah penggunaan tag HTML yang memiliki makna sesuai dengan isi kontennya.

Contoh Tag Semantic

Beberapa tag semantic antara lain: header, nav, main, section, article, aside, dan footer.
