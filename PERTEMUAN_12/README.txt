PERTEMUAN 12 - Praktik JavaScript Sederhana

ISI FOLDER
- index.html : struktur halaman web, input nama, tombol, dan area hasil.
- script.js  : kode JavaScript untuk alert(), console.log(), prompt(), dan sapaan pada halaman.

TUJUAN
Membuat satu halaman web sederhana yang menerima nama pengguna dan mempraktikkan alert(), console.log(), serta prompt().

APLIKASI
Cukup menggunakan Visual Studio Code dan browser (Chrome, Edge, atau Firefox).
XAMPP tidak diperlukan karena proyek ini hanya menggunakan HTML dan JavaScript sisi klien, tanpa PHP atau database.

CARA MENJALANKAN
1. Ekstrak PERTEMUAN_12.zip.
2. Buka Visual Studio Code.
3. Pilih File > Open Folder, lalu buka folder PERTEMUAN_12.
4. Buka file index.html.
5. Jalankan dengan membuka index.html di browser. Jika sudah memasang ekstensi Live Server, klik kanan index.html lalu pilih Open with Live Server (opsional).
6. Masukkan nama, lalu klik tombol Klik Saya.
7. Alert akan menampilkan sapaan. Setelah alert ditutup, prompt meminta nama sekali lagi. Pesan console dapat dilihat melalui Developer Tools > Console (biasanya tekan F12 atau Ctrl+Shift+J di Windows/Linux, atau Cmd+Option+J di Mac).

CATATAN
Nama yang dimasukkan pada kolom dipakai untuk alert, console.log(), dan teks sapaan pada halaman. prompt() juga dipanggil untuk mempraktikkan dialog input sesuai instruksi tugas.
