PERTEMUAN 12 - Praktik JavaScript Sederhana

Pada pertemuan ini dibuat halaman web sederhana untuk mempraktikkan penggunaan JavaScript.

Materi yang diterapkan:
- alert() untuk menampilkan pesan.
- console.log() untuk menampilkan informasi pada console.
- prompt() untuk meminta input dari pengguna.
- Menampilkan sapaan berdasarkan nama yang dimasukkan.

- index.html
- script.js
